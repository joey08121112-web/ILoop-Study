# 日新 · FluEvo：物理信息引导参数进化的传染病流式预测

> BoHack 2026 天津青年黑客松「日新」赛道参赛作品
>
> SEIRS 机理模型 · 集合卡尔曼滤波（EnKF）· CUSUM 变点检测 · 多模型贝叶斯路径选择 · 人工确认

## 主张

形势突变（变点）时，数据的大幅偏离源于机理参数发生了变化，而变化的方向有多种可能、表象却相似——是封城压低了传播率？治疗见效抬高了康复率？还是人群免疫结构变了？本作品让模型在变点处枚举候选的参数进化路径并给出概率，再借助外界的物理信息——人的判断、搜索指数——帮它选对方向，沿选定的路径继续进化。

## 评审演示：跑两次

对应赛题「现场跑两次、第二次比第一次有提升」：

```bash
python3 run_demo.py           # 第一次：发现变点，但参数不进化 → 预测持续大幅偏离
python3 run_demo.py           # 第二次：参数进化（选错路径 / 选对路径）→ 与第一次对比
python3 run_demo.py --reset   # 清除演示记录，回退到第一次之前
```

VS Code 用户可以直接打开 `run_demo.py` 按 F5，或在「运行和调试」里选「运行演示」。结果输出到桌面「日新_演示结果」文件夹。

**第二次比第一次的提升**（三组展示数据平均；报警后第 3 天出发的预测 MAPE）：

| 预测期 | 第一次：不进化 | 第二次：进化·选错路径 | 第二次：进化·选对路径 |
|---|---|---|---|
| 未来 7 天 | 175% | 40% | **13%** |
| 未来 14 天 | 288% | 50% | **12%** |
| 未来 21 天 | 474% | 63% | **14%** |

## 作品学到了什么

- **预训练**（`fluevo/pretrain.py`）：从前 5 年数据学出季节传播率曲线与免疫消退率。初始猜测故意取离真值较远的值，也能收敛——季节幅度估 0.126（真值 0.12），基础传播率 0.412（真值 0.42）。
- **在线微调**：模型无误时，每天按卡尔曼增益微调干预项与康复率项（随机游走 0.5% / 0.2%）。
- **变点处进化**（`fluevo/engine.py`）：CUSUM 报警后，为四条候选路径（传播率变了、康复率变了、易感人群突增、虚警）各开一组滤波器，从多个可能的变点起点重放，按贝叶斯公式更新每条路径的概率；人工确认采纳，人不给信息时自动取概率最高者。
- **阈值的依据**：报警门槛 h 由「模型无误时平均 5 年才误报一次」反推（Siegmund 近似公式）——有搜索指数时 h = 7.1，只有病例时 h = 6.4。
- **可回退**：候选路径不被采纳就保持原参数；`--reset` 一键清空演示状态；选错路径后系统平均再报警约 1 次自行纠正。

## 20 个种子的统计（`out_flu/results.json`）

- 封城后平均 **3.6 天**报警；变点日估计准确（三组都估为第 195 天，真值 195）。
- 无变化年份每年误报 **0.05 次**。
- 不给人工信息时自动选对路径的比例：有搜索指数 **100%**；只有每日新增时 42%–68%——这正是需要人来确认的地方，也是物理信息的价值所在。

## 运行

依赖：Python 3 与 numpy、matplotlib、scipy（见 `requirements.txt`；重做 PPT 另需 python-pptx 和 Pillow）。

| 目的 | 命令 |
|---|---|
| 评委演示（跑两次） | `python3 run_demo.py` |
| 交互式逐日运行，变点处询问人选哪条路径 | `python3 -m fluevo.run --scenario lockdown` |
| 实时网页看板 | `python3 -m fluevo.live`，打开 <http://127.0.0.1:8767> |
| 20 个种子汇总（约 3 分钟） | `python3 -m fluevo.experiment` |
| 图 1–6 / 变点指标与图 7 | `python3 -m fluevo.plots 2` / `python3 -m fluevo.metrics` |

交互式运行的情景可选 `lockdown`（传播率 ×0.6）、`treatment`（康复率 ×1.6）、`reopen`（传播率 ×1.4）、`none`；`--no-search` 去掉搜索指数，`--auto` 全程不询问。

## 局限

- 全部是仿真，仿真器与滤波器用同一套 SEIRS 结构；潜伏期、报告率、基准康复率、人口当作已知。
- 「搜索指数正比于当前正在生病的人数」是一个假设，区分传播率与康复率的能力依赖它。
- 只测了一种变点（流行上升期封城，传播率 ×0.6）。
- 「选错路径明显伤害预测」只在有搜索指数时成立；只用每日新增时，选错路径对短期病例预测影响很小，主要后果是把原因解释错。

更多细节见 `技术报告_流感版.md` 第 11 节（局限与展望）。
